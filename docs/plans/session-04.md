## Amendments to session-03 binding decisions (PR1-T5, T9, T10, T11, T21)

The session-03 plan v4 is the design reference. The following session-04
amendments supersede specific session-03 items:

| Amendment | Session-03 spec | Session-04 decision | Rationale |
|---|---|---|---|
| **A1 — cull_scores column naming** | `scorer TEXT`, `score REAL`, `scored_at_unix_seconds INTEGER` | **`model_slug TEXT`, `aesthetic_score REAL`, `scored_at_unix_seconds INTEGER`** | `model_slug` aligns with `camera_slug` convention; `aesthetic_score` is more descriptive than generic `score`. `scored_at_unix_seconds` kept exactly (fixes session-04 v1's truncated `scored_at`). |
| **A2 — CullStats field list** | `in_flight, scored, inference_failed, decode_failed, file_missing, content_changed, catalog_inconsistency, derive_failed` (8 fields) | **`walked, scored, already_scored, decode_failed, infer_failed, file_missing, content_changed, catalog_inconsistency, catalog_written, derive_failed`** (10 fields) | `in_flight` → `walked` (more meaningful for cull; photos are already catalogued); `inference_failed` → `infer_failed` (shorter, symmetric with decode_failed); added `already_scored` + `catalog_written`; restored `file_missing` + `content_changed` (PR1-T17: needed for per-photo dispatch). |
| **A3 — Preprocessing normalization** | "ImageNet mean/std" (session-03 plan lines 256-258 — incorrect) | **MobileNet `preprocess_input`: `pixel / 127.5 - 1.0` per channel** | Session-03 was wrong; `idealo/image-quality-assessment` uses `tf.keras.applications.mobilenet.preprocess_input` which maps `[0,255]→[-1,1]`. Session-04 is correct. |
| **A4 — `run_cull` return type** | `anyhow::Result<u8>` (session-03 plan line 492) | **`ExitCode`** | Aligns with `run_ingest`'s pattern; errors handled internally inside `run_cull`; cleaner public API. |
| **A5 — ModelRegistry / LoadedModel eliminated** | Three-type hierarchy: `VerifiedModelBytes → LoadedModel → Nima` | **Two-type: `VerifiedModelBytes → Nima`** | `LoadedModel` was an intermediate wrapper without independent value; `Nima` constructs per-worker `Session` lazily in `thread_local!` directly from `VerifiedModelBytes`. SHA-256 trust boundary is preserved. |

### D1c — `NimaScore` + `Nima` + `Error`

**`Error` enum** (`#[non_exhaustive]`, thiserror):
- `ModelSha256Mismatch { expected: String, actual: String }`
- `ManifestParse { source: Box<dyn std::error::Error + Send + Sync> }`
- `ManifestNotFound { path: PathBuf }`
- `ModelLoad { source: Box<dyn std::error::Error + Send + Sync> }`
- `InferenceFailed { path: PathBuf, source: Box<dyn std::error::Error + Send + Sync> }`

Note: `NimaInferenceCause` dropped; `InferenceFailed.source` is the boxed ort error.
The v1 plan's `NimaInferenceCause` name was a plan-level inconsistency (PR1-T22).

**`NimaScore`** newtype over `f32`:
- `from_f32(v: f32) -> Result<Self, Error>`: rejects NaN, Inf, and values outside
  `[1.0, 10.0]`. All-zeros softmax → weighted-mean = NaN → caught here → `Err`.
  Note: this case is intentional (degenerate model output is not a valid score).
- `from_catalog_f64(v: f64) -> Result<Self, Error>`: saturating cast to `f32`;
  WARN via `tracing::warn!` if `(v as f32 - v as f32).abs() > 1e-6`; then validate
  range. (PR1-T24: needed when reading back scores from `cull_scores.aesthetic_score`)
- `Ord` via `f32::total_cmp` (sound: NaN rejected at construction)
- `Copy + Clone + PartialEq + Eq + PartialOrd + Ord`

**`Nima`**:
- Wraps `VerifiedModelBytes`
- `pub fn score(rgb: &RgbImage) -> Result<NimaScore, Error>`
  1. Resize `rgb` to 224×224 bilinear into a **new 224×224 `Vec<u8>` buffer**
     (NOT "in-place" — `&RgbImage` is immutable; PR1-T31)
     - Implementation: hand-rolled bilinear downsample (~60 LoC); no `image` crate dep
       (the only operation needed is one 2D bilinear downsample; adding the full `image`
       crate dependency tree for this is disproportionate)
  2. Apply A3 normalization: `(pixel as f32 / 127.5) - 1.0` per channel → `Vec<f32>`
     shape `[1, 224, 224, 3]` (NHWC per TF-origin model)
  3. Create ort input tensor from the `Vec<f32>`
  4. Run inference via **thread-local session** (PR1-T1 pattern — no `get_or_insert_with`):
     ```
     SESS.with(|cell| {
         let mut guard = cell.borrow_mut();
         if guard.is_none() {
             match Session::builder()?.commit_from_memory(&self.bytes) {
                 Ok(sess) => *guard = Some(sess),
                 Err(e) => return Err(Error::ModelLoad { source: Box::new(e) }),
             }
         }
         let sess = guard.as_mut().unwrap(); // safe: just inserted
         sess.run([input])
             .map_err(|e| Error::InferenceFailed { path: self.path.clone(), source: Box::new(e) })
     })
     ```
     Construction failure propagates as `Err(ModelLoad)`; `thread_local!` slot
     stays `None` so next photo retries. The `unwrap()` on line 7 is safe because
     the `if guard.is_none()` branch always sets `Some(_)` or returns `Err`.
  5. Extract 10-class softmax output; compute `sum((i+1.0) * p[i] for i in 0..10)`
  6. `NimaScore::from_f32(mean)` → surface validation error as `InferenceFailed`
- `static_assertions::assert_impl_all!(Nima: Send, Sync)`
- **Sub-component review fires here** (`docs/code-reviews/session-04-photohelper-ai-round{1,2}.md`)

**`pub fn read_raw_rgb(path: &Path) -> Result<RgbImage, Error>`** in `decode.rs`:
1. Open with `LibrawGuard`, call `libraw_unpack`
2. Call `libraw_dcraw_process` (AHD demosaic, default `output_bps = 8`)
3. Call `libraw_dcraw_make_mem_image`; get raw pointer
4. **SAFETY comment** (required by `undocumented_unsafe_blocks = "deny"`):

5. Runtime assert: `bits == 8 && colors == 3` (else `RgbConversionFailed`)
6. Copy `data[0..data_size]` into `Vec<u8>`
7. Call `libraw_dcraw_clear_mem` (free LibRaw's buffer)
8. `RgbImage::new(pixels, NonZeroU32::new(width).ok_or(...)?, ...)` (validates invariant)
9. Return `Ok(rgb_image)`

`RawDecodeCause::RgbConversionFailed { bits, colors }` variant added to `Error`.

### D3 — `run_cull` + `cull` subcommand rewire

**`CullStats`** with 10 `AtomicU64` fields (A2 amendment; PR1-T9):

| Field | Incremented when |
|---|---|
| `walked` | Each `CullRow` from `unsuperseded_unscored_rows` |
| `scored` | `insert_cull_score` returns `Inserted` |
| `already_scored` | `insert_cull_score` returns `AlreadyScored` |
| `decode_failed` | `read_raw_rgb` returns `Err` |
| `infer_failed` | `Nima::score` returns `Err` |
| `file_missing` | `read_raw_rgb` returns `Io { kind: NotFound }` specifically |
| `content_changed` | `PhotoId::derive` re-derivation: `current_id != catalog_id` |
| `catalog_inconsistency` | `insert_cull_score` FK violation (photo deleted mid-run) |
| `catalog_written` | `insert_cull_score` returns `Ok(_)` (any outcome) |
| `derive_failed` | `PhotoId::derive` returns `Err` (I/O failure reading file for re-derivation) |

**`run_cull`** pipeline per photo (inside rayon `par_bridge().for_each()`):
```
for each CullRow { photo_id, source_path } from unsuperseded_unscored_rows:
1. Re-derive PhotoId from source_path (PR1-T17: content-change detection restored)
   - Err → derive_failed++; continue
   - Ok(current_id) if current_id != photo_id → content_changed++; continue
2. read_raw_rgb(source_path)
   - Err(Io { NotFound }) → file_missing++; continue
   - Err(_) → decode_failed++; continue
3. Nima::score(rgb)
   - Err → infer_failed++; continue
4. insert_cull_score(photo_id, MODEL_SLUG, score, now())
   - Err (FK violation) → catalog_inconsistency++; tracing::warn! with source_path
   - Ok(Inserted) → scored++; catalog_written++
   - Ok(AlreadyScored) → already_scored++; catalog_written++
```

**`MODEL_SLUG`** constant: `"nima-aesthetic-v1"` (matches session-03 plan's scorer placeholder)

**`--strict` predicate** (PR1-T14): exits non-zero if
`decode_failed + infer_failed + derive_failed > 0`.
`catalog_inconsistency`, `file_missing`, `content_changed` do NOT trigger strict
(transient/user-caused conditions, not inference pipeline failures).

**"Nothing useful happened" check**: if `walked > 0 && scored + already_scored == 0`,
exit `EX_USAGE` regardless of `--strict` (analogous to `ingest`'s all-JPG check).
