## Binding design decisions (from session-03 plan v4)

These are locked — not up for re-evaluation in plan-review:

1. **`Session::run` is `&mut self`** (confirmed from ort source in ANL-002) →
   per-worker `thread_local!`; NOT one shared `Arc<Nima>`.
2. **`run_cull` signature**: `fn run_cull(cli: &Cli, args: &CullArgs, model: &VerifiedModelBytes) -> ExitCode`
3. **No `Scorer` trait, no `Migration` trait** — one scorer (`Nima`), one migration
   (`apply_v1_to_v2`).
4. **`SCHEMA_VERSION = 2`** — `Catalog::open` match arm handles 0, 1, 2.
5. **`NimaScore: Copy + Clone + PartialEq + Eq + PartialOrd + Ord`** — `Ord` via
   `f32::total_cmp`; constructor validates `[1.0, 10.0]`.
6. **`VerifiedModelBytes::from_manifest(model_dir, name)`** — reads bytes, SHA-256
   checks against manifest.toml, returns `Self` wrapping `Arc<[u8]>`.
7. **`PhotoId::derive` in `for_each` closure uses `match`** (not `?`) to accumulate
   `derive_failed` counter per R3-T2.
8. **AHD demosaic** (LibRaw default) for NIMA preprocessing — stop-gap TD-012.
9. **`ort = { version = "=2.0.0-rc.12", default-features = false, features = [...] }`**
   exact pin (TD-014 tracks upgrade to stable).
10. **`cull_scores.photo_id` FK without `ON DELETE CASCADE`** (no delete path in v0.1).

### D1b — `VerifiedModelBytes`

- Private `Arc<[u8]>` interior; `from_manifest(model_dir: &Path, name: &str) -> Result<Self>`:
  reads `{model_dir}/{name}.onnx`, reads SHA-256 from `{model_dir}/manifest.toml`,
  verifies match, wraps in `Arc<[u8]>`.
- `static_assertions::assert_impl_all!(VerifiedModelBytes: Send, Sync)`.
- Unit test: `from_manifest` with mismatched SHA-256 returns `Err(Error::ModelSha256Mismatch)`.

### D1c — `NimaScore` + `Nima` + `RgbImage` + `Error`

- `NimaScore` newtype `f32` with `Ord` via `total_cmp`; `from_f32(f32) -> Result<Self>`
  rejects NaN / outside `[1.0, 10.0]`.
- `Error` enum (`#[non_exhaustive]`, thiserror): `ModelSha256Mismatch`, `ManifestParse`,
  `ModelLoad`, `InferenceFailed { path, source }`.
- `RgbImage { pixels: Vec<u8>, width: u32, height: u32 }` with invariant check.
- `Nima::score(rgb: &RgbImage) -> Result<NimaScore>`:
  - resizes to 224×224 (bilinear, in-place in pixels buffer),
  - applies mobilenet `preprocess_input` (scale `[0,255]` → `[-1,1]`),
  - `thread_local!` `RefCell<Option<Session>>` — `borrow_mut(); .get_or_insert_with(|| Session::new(bytes))`,
  - runs ort `Session::run`, returns weighted mean of 10-class output.
- `static_assertions::assert_impl_all!(Nima: Send, Sync)`.
- **Sub-component review fires here** (`docs/code-reviews/session-04-photohelper-ai-round{1,2}.md`).

### D1e — `read_raw_rgb` in `photohelper-raw`

- `pub fn read_raw_rgb(path: &Path) -> Result<RgbImage, Error>` in
  `crates/photohelper-raw/src/decode.rs`:
  - Opens with `LibrawGuard`, calls `libraw_dcraw_process`, `libraw_dcraw_make_mem_image`
  - Copies the 3-channel 8-bit output into `RgbImage { pixels, width, height }`
  - Frees the mem-image buffer; `RgbImage` takes ownership of a `Vec<u8>` copy
  - `RawDecodeCause::RgbConversionFailed` variant added to `Error`
  - SAFETY comment per `undocumented_unsafe_blocks` lint
- Integration test: `read_raw_rgb` on CC0 fixture → `width * height * 3 == pixels.len()`

### D2a — Catalog schema v2 (`cull_scores` table)

  creates `cull_scores` table + indexes + sets `PRAGMA user_version = 2`.
- `Catalog::open` match arm: `0 => { init_v1(); apply_v1_to_v2()? }`, `1 => { apply_v1_to_v2()? }`,
  `2 => {}`, other → `CatalogSchemaTooNew`.
- `PRAGMA foreign_keys = ON` added to `Catalog::open` init sequence.
- **Sub-component review fires here** (`docs/code-reviews/session-04-catalog-migration-round{1,2}.md`).

### D2b — `Catalog::insert_cull_score` + integration test

- `pub fn insert_cull_score(&self, photo_id: PhotoId, model_slug: &str, score: NimaScore, scored_at: i64) -> Result<InsertScoreOutcome>`
  where `InsertScoreOutcome: { Inserted, AlreadyScored }`.
- `BEGIN IMMEDIATE` per insert; `INSERT OR IGNORE` semantics for idempotency.
- Migration integration test: v1 DB → `Catalog::open` → assert v2; insert `photos` row;

  returns 1 row.

### D3 — `run_cull` implementation + `cull` subcommand rewire

- `crates/photohelper-cli/src/commands/cull.rs` (new file):
  - `run_cull(cli: &Cli, args: &CullArgs, model: &VerifiedModelBytes) -> ExitCode`
  - `CullArgs` clap struct (no `--model-path`; `--strict` flag)
  - Heartbeat thread (copied from `run_ingest` — TD-016 stop-gap, filed inline)
  - `CullStats` with 8 `AtomicU64` fields
  - rayon `par_bridge` over `Catalog::all_rows()` → per-row: `read_raw_rgb` → `Nima::score`
    (via `thread_local!`) → `insert_cull_score`
  - `PhotoId::derive` uses `match` in `for_each` (not `?`)
  - Error dispatch: decode fail → `decode_failed`++; infer fail → `infer_failed`++; catalog
    inconsistency (photo_id not found after upsert) → `catalog_inconsistency`++
  - `--strict`: exit non-zero if `decode_failed + infer_failed > 0`
  - Summary on stderr: `walked: N, scored: N, already-scored: N, decode-failed: N,
    infer-failed: N, catalog-inconsistency: N, derive-failed: N`
- `main.rs`: `Command::Cull => { let model = VerifiedModelBytes::from_manifest(...)? ; run_cull(&cli, &args, &model) }`
- **Negative test**: `cull --help` no longer emits stub message (existing test `cull_help_does_not_emit_stub_message` now asserts exit 0 only — stub retired).
- **Integration test** `cull_scores_real_canon_r8_cr3_fixture`: ingest CC0 fixture, `run_cull`,
  assert 1 row in `cull_scores` with `aesthetic_score ∈ [1.0, 10.0]`.
